# 돈 관리 자동화 웹앱 설계

참고 영상: 혼잡스 "돈 관리 7가지 AI한테 전부 맡겨 봤습니다 | 모조리 자동화 #2" (https://youtu.be/Q0glU3lk6Js)

## 목표
카드사·은행에서 내려받은 엑셀을 끌어다 놓으면 가계부, 새는 돈, 카드 실적, 연말정산 미리보기, 통장 쪼개기, 주간 브리핑이 채워지는 웹앱. 데이터는 사용자 PC 브라우저 밖으로 나가지 않는다.

## 확정된 결정
- 형태: 빌드 없는 정적 사이트(HTML + ES 모듈 + SheetJS 파일 동봉). GitHub Pages 배포는 사용자 최종 승인 후 마지막에 한다.
- 데이터: 브라우저 IndexedDB에 누적 저장. 백업/불러오기(JSON) 제공. 가계부 표는 엑셀로도 내보낸다.
- 엑셀 형식: 자동 감지(헤더 행 탐색, 열 이름 추정). 실패하면 열 지정 화면. 매핑은 저장한다.
- 영수증 사진 판독: 하지 않는다. 직접 입력 폼 + 카드 내역의 병원·약국 거래 자동 합산.
- 투자 X-ray(ETF 합산): 이번 범위에서 제외.
- 주간 브리핑: 자동 알림 없이 탭에서 항상 최신 요약을 보여 준다.

## 원칙
- 비밀번호·인증서·보안카드는 받지 않는다. 이체·해지는 사람이 직접 한다.
- 세금 화면에는 "준비용, 홈택스에서 최종 확인" 문구와 세법 기준 연도를 표시한다.

## 구조
데이터 흐름: 엑셀 업로드 → 헤더/열 감지 → 표준 거래로 변환 → 미리보기(추가 N건, 중복 M건) → 사용자 확인 → 중복 제거 후 저장 → 탭들이 전체 저장 데이터로 계산.

코드 단위(각각 독립 테스트 가능):
- parser: 헤더·날짜(여러 형식)·금액("12,000원" 등) 표준화, 취소 결제 제외, 외화는 추정치 표시, 읽지 못한 행 목록 반환.
- store: 거래 누적, 중복 제거, 규칙·설정, 백업/불러오기, schemaVersion 마이그레이션.
- classifier: 가맹점 → 카테고리(기본 15개), 모르는 곳은 사용자에게 묻고 규칙 저장.
- 계산 모듈: ledger, leaks, cardPerformance, yearEndTax, accountSplit.
- ui: 탭 5개(가계부 / 새는 돈 / 카드 실적 / 연말정산 / 통장 쪼개기·주간 브리핑), 업로드 화면, 설정 화면.

## 기능 규칙
### ① 가계부
- 지출 합계에서 카드대금, 저축 입금, 받은 돈은 제외(이중 집계 방지).
- 할부는 "할부 나누기"로 월별 분할.
- 월별 합계, 카테고리별 SVG 막대 차트.

### ② 새는 돈
- 정기결제: 같은 가맹점 + 비슷한 금액 + 비슷한 날짜가 2개월 이상 반복. 할부, 병원, 쇼핑 카테고리 제외. 가맹점 이름 부분 문자열로 판별하지 않는다(예: "subscription" 속 "PT").
- 이상 신호: 갑작스런 시작, 가격 인상, 같은 종류 중복(클라우드·음악 등), 소액 반복결제.
- 해지 체크박스: 월 절감액, 연 절감액(×12)을 즉시 계산해 통장 쪼개기의 저축 칸에 반영. 해지는 사용자가 직접 한다.
- 배달 등 습관 지출은 월 N회·연 N원만 표시.

### ③ 카드 실적
- 입력: 카드 이름, 전월 실적 기준, 카테고리별 혜택률. 업로드 시 파일에 카드/계좌 이름을 붙인다.
- 출력: 실적 달성 여부, 놓친 혜택 금액, 남은 실적 금액.

### ④ 연말정산 미리보기
- 입력: 총급여, 의료비, 기부금, 안경, 문화비. 의료비 후보는 카드 내역에서 자동 추출, 사용자 확정.
- 3% 문턱 체크: 총급여 × 3% 계산 후 연말 예측으로 공제 가능 여부 판단, 못 넘으면 "공제 0원" 경고.
- 분류: 치료용 의약품 포함, 영양제·반창고 제외, 안경은 시력교정용 연 50만 원 한도.
- 헬스장 문화비 공제는 "확인 필요"로만 표시.
- 한도·비율은 한 파일의 상수로 모은다.

### ⑤ 통장 쪼개기
- 월급은 "급여"로 표시된 입금만 인정(더치페이 입금 제외).
- 통장 4개: 고정비, 생활비(지출 10% 절감 목표, 주 단위 금액), 비상금, 저축·투자. 비율은 조정 가능.
- 비상금 목표 = (고정비 + 생활비) × 3개월, 달성 개월 수 계산.

### ⑦ 주간 브리핑
- 지난주 생활비와 예산 대비 차이, 이번 주 나갈 고정 지출, 카드 실적 현황.

## 저장 구조(IndexedDB)
- transactions: 날짜, 가맹점, 금액, 통화, 카드/계좌 이름, 카테고리, 취소 여부, 출처 파일명, 중복 키(날짜+가맹점+금액+계좌).
- rules: 가맹점 → 카테고리, 카드사별 열 매핑.
- settings: 월급일, 총급여, 카드 혜택 규칙, 통장 비율, 연말정산 입력값.
- 모든 레코드에 schemaVersion. 열 때 구버전 자동 변환.
- 중복: 같은 파일 안의 동일 거래는 모두 보존, 다른 파일과 겹칠 때만 합친다.

## 오류 처리
- 열을 못 찾으면 열 지정 화면.
- 해석 불가 행은 건너뛰되 "N행을 읽지 못했습니다" 목록 표시.
- 저장 전 미리보기와 사용자 확인.
- 저장 실패(용량·시크릿 모드)는 경고와 백업 안내.
- 형식이 맞지 않는 백업은 기존 데이터를 덮어쓰지 않고 중단.

## 테스트
- Node 자동 테스트: parser, 중복 제거, classifier, 정기결제 판별, 3% 문턱, 통장 배분.
- 회귀 테스트 4건: 할부를 구독으로 오인 / 병원비를 가격 인상으로 오인 / "PT" 문자열 오분류 / 더치페이를 월급으로 집계.
- 합격 기준: 약 330건 가상 데이터에서 월평균 지출과 새는 돈 합계가 기대값과 일치.
- 화면은 브라우저에서 업로드부터 5개 탭까지 직접 확인.

## 배포
- 개발과 샘플 확인은 로컬에서. 사용자가 최종 검토·승인한 뒤에만 GitHub 저장소 생성과 GitHub Pages 공개를 진행한다(외부 공개 작업이므로 그 시점에 다시 확인).
- SheetJS는 CDN이 아니라 파일로 동봉.

## 범위 밖
투자 X-ray, 영수증 사진 판독, 카드 상품안내서 자동 분석, 주간 자동 알림, 모바일 전용 UI(반응형만 기본).
