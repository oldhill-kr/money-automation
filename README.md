# 돈 관리 자동화

카드·은행에서 내려받은 엑셀을 올리면 가계부, 새는 돈, 카드 실적, 연말정산 미리보기, 통장 쪼개기, 주간 브리핑을 보여 주는 웹앱입니다. 서버 없이 브라우저에서만 돌고, 데이터 저장 위치는 설정·백업 탭의 "저장 위치"에서 고릅니다: 브라우저 안에만(기본, IndexedDB) / 내 PC 폴더(로컬 모드) / 구글 드라이브 폴더(클라우드 모드). 폴더 모드는 `money-data.json`(+직전 `money-data.prev.json`)을 고른 폴더에 쓰며 크롬·엣지가 필요합니다.

## 실행

```
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. (파일을 더블클릭해서 열면 ES 모듈이 막히므로 위처럼 작은 서버를 켜야 합니다. 배포하면 이 단계는 필요 없습니다.)

## 체험하기

- 상단의 "예시 데이터로 먼저 보기" 버튼 (가상 인물 3개월 치)
- 또는 `demo/` 폴더의 엑셀 3개(혼잡카드, 체크카드, 국민은행)를 상단의 '파일 업로드' 버튼으로 연 창에 끌어다 놓기. 다시 만들려면 `node tests/make-demo-xlsx.js`.
- 카드 실적 탭은 설정 탭에 카드 이름 `혼잡카드 Plus`, 계좌 이름 `혼잡카드`를 입력하면 보입니다(데모 버튼은 자동 입력).

## 탭 구성

① 가계부(직접 추가·한 건 삭제·열 정렬) · ② 새는 돈 · ③ 카드 실적(카드 여러 장, 지역화폐 캐시백) · ④ 연말정산 · ⑤ 통장 쪼개기 · ⑥ 월간 브리핑 · ⑦ 예산(카테고리별 월 예산) · ⑧ 수입·저축(저축률). 설정·백업은 오른쪽 위 버튼입니다.

- 선불·지역화폐 충전, 본인 이체는 지출·수입에서 뺍니다(`kind: transfer`).
- 구글 드라이브 폴더를 두 PC에서 쓰면, 저장할 때 마지막으로 맞춘 시점 대비 "내가 바꾼 것"만 최신 파일에 얹어 합칩니다(`threeWayMerge`). 삭제한 거래가 되살아나지 않습니다.

## 테스트

```
npm test
```

## 구조

- `src/` 계산 모듈(parser, store, classifier, ledger, leaks, cardPerformance, yearEndTax, accountSplit, monthlyBriefing)은 화면과 무관한 순수 코드입니다.
- `src/ui/` 화면, `src/db.js` IndexedDB 저장.
- `src/constants.js` 세법 수치와 기준 연도(해마다 확인하세요).
- `vendor/xlsx.full.min.js` SheetJS 0.20.3 (외부 CDN을 쓰지 않습니다).

## 알려진 한계

- 세법 수치(의료비 3% 문턱, 안경 50만 원 한도, 문화비 7천만 원 기준)는 2026년 기준으로 적어 둔 값입니다. 최종 확인은 홈택스에서 하세요.
- 외화 결제는 고정 환율(1,400원)로 추정합니다.
- 카드사 환불(음수 금액)은 "취소"로 보고 지출에서 뺍니다.
- 투자 X-ray, 영수증 사진 판독, 자동 알림은 이번 범위에 없습니다.
